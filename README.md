# China Travel Story Map 🗺️

A responsive, high-performance web interactive map to record, visualize, and share your travel footprint across China.

## ✨ Key Capabilities
- **Nationwide Coverage**: Complete dataset of 370+ cities across 34 provincial divisions.
- **Responsive Adaptability**: Seamless transition across desktop, mobile portrait, and landscape views.
- **Offline First**: IndexedDB-backed offline storage with graceful localStorage fallbacks.
- **Vector Export**: Generate clean, printable SVG route charts.
- **PWA Ready**: Installable to desktop and mobile home screens with offline caching.

## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/kaige-mr/china-travel-story-map.git

# Install dependencies
npm install

# Start development server
npm run dev

# Run unit tests
npm test
```
